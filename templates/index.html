About the Project

Academic Minor Project Documentation

1. Project Objective

The objective of this Minor Project is to design and implement an automated Smart Traffic Monitoring System using Computer Vision and Deep Learning. The system automates the detection, classification, counting, and density estimation of vehicular traffic from recorded surveillance or drone footage without human intervention.

Traffic Video → YOLO Vehicle Detection → Temporal Tracking & Counting → Rule-Based Density → Academic Dashboard

2. Technology Stack

  • Programming Language: Python 3.13
  • Object Detection: YOLO26n / YOLO11n (Pretrained on COCO dataset)
  • Computer Vision: OpenCV (Video frame decoding, drawing, video writing)
  • Deep Learning: PyTorch & Ultralytics
  • Backend: Flask (REST API, background worker threads)
  • Frontend: Semantic HTML5, CSS3, JavaScript (Fetch API)

3. Key Methodology for Viva / Evaluation

How Duplicate Counting is Prevented:

Rather than simply counting detected bounding boxes in each isolated frame (which would repeatedly count the same vehicle 30 times every second), this system employs ByteTrack temporal tracking. Each detected vehicle is assigned a persistent unique track ID across frames. A vehicle is registered only once upon crossing the reference virtual line or first entering the monitoring zone.

Why Rule-Based Density Classification:

In accordance with the approved B.Tech Minor Project scope, traffic density (Low, Medium, High) is derived through a calibrated rule-based threshold function based on the total vehicle volume and active load. This provides a transparent, explainable, and configurable decision-making mechanism suitable for academic demonstration.

4. Minor Project Scope Boundaries

In accordance with Minor Project guidelines, complex enterprise extensions (such as adaptive traffic light signaling, accident prediction, ANPR number plate recognition, multi-camera re-identification, or heavy database backends) are reserved for future Major Project iterations.
